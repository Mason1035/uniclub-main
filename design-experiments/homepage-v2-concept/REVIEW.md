## 3. 字体

思源宋体承担当下的大字与记忆中的标题；思源黑体承担目录与说明；Schibsted Grotesk 承担英文、日期、Pulse 数字；得意黑仅在 Ending 的短语出现。沿用 Typography Lab 的字体源，制作本页紧凑子集，没有新的大字体下载。

## 4. Grid

桌面 12 栏、平板 8 栏、手机 4 栏。断点为 1200 / 600px。外边距桌面 `clamp(32px, 4.2vw, 80px)`，平板 32px，手机 20px；gutter 24 / 18 / 12px；最大内容宽度 1600px；正文上限 32em。

标题偏移、元数据栏、大图与小图均使用明确栏位。NOW 的影像突破到全宽；Pulse 是连续构图。评审面板可显示同一套实际网格。

## 5. Art Direction 核心

**班级的时间刊物。** THE LIVING DIGITAL CLASS 被组织成“在一起／在发生”：从今天的课后日常，进入下次相聚与共学，再进入过去的故事与人的关系。纸色、墨色、灰绿中性影像、少量档案深红。没有额外纸纹或噪点覆盖。

Editorial 的大字与节奏占主导；文化机构式的索引与时间关系提供秩序；小型导航和对话框承担当代产品感；年份切换提供有限实验性；页角伙伴只在结尾出现一次。

## 6. Arrival

“在一起。”位于左上，“在发生。”沿网格偏向右下；英文 `a class, in time.` 占据另一块留白。日期、班级身份与一句“今天的相聚，会成为明天的记忆”保持小尺度。没有开场摄影或大 CTA。

## 7. Class Pulse

03 最大，并用深红确定当前的相聚；12 位于上方偏右，08 落在更低的位置。数字和留白直接组成页面，辅助文字跟随各自数值。三组数字来自活动、日常、资料的本地样本长度，明示“原型样本统计 / 非实时班级数据”。

## 8. Living Timeline

桌面左侧大年份自然 sticky，右侧包含不同长度的故事、竖图、横图与一页尚未写完的空白。IntersectionObserver 更新年份与当前位置。可以直接跳到某条记忆；没有滚动锁定或横向陷阱。

手机取消 sticky，年份成为每一条记忆的入口。所有时间均标为示例，并保留月份精度；辅助技术可以读到完整年份与月份。

## 9. Photography

实际班级摄影的来源与授权仍待确认，因此使用三张原创、本地 SVG 中性光影构图。A 是窗格与光，B 是层叠空间，C 是桌面纸张。验证全宽、竖向细节、非对称组合与时间中的不同裁切。

每张图片的 caption / alt 明确说明占位，不伪造班级场景、同学或摄影者。三张图均很小，当前采用直接加载；未来真实摄影需要按实际尺寸重新决定懒加载和响应式图片策略。

## 10. Motion Language

开场两行文字一次性 mask reveal；导航下划线解释可点击性；对话框有短暂裁切打开；年份切换与当前时间位置相连；页角伙伴只在点击后点头。

自然滚动，全页没有统一 fade-up、自动计数或自定义光标。Reduced 取消 CSS 动画、过渡和 Web Animations；系统 reduce 优先于面板中的 Full。使用 CSS、IntersectionObserver、原生 Web Animations，没有引入动画库。

## 11. Mobile 重构

- 标题两行在 4 栏里重新错位；英文变为单行。
- 日期与说明组成短横行；导航收进完整目录对话框。
- NOW 改为日期横行、标题、短文、竖向大图的阅读顺序。
- Pulse 先是一个巨大 03，再是错位的 12 / 08。
- Upcoming 的时间改到标题下方；资源类型移到第二行。
- Class Life 大图竖裁，小图错位；Timeline 年份改为组内标题。

## 12. Dark Mode

沿用 Typography Lab 的灰绿夜间底色，而非纯黑。文字变为暖灰白；红色提高明度，保持阅读与焦点对比。影像保留自身色彩，没有反相滤镜。Light / Dark 均有实际截图。

## 13. 最具有 ClassHub 独特性的三个瞬间

1. **NOW**：日期与课表之外的共同时间联系起来，“下课以后，把秋天多留了一会儿”。班级不是抽象组织，而是日常中的相聚。
2. **Class Pulse**：未来的相聚、已经能留下的日常、一起分享的知识，用三种尺度组成正在发生的班级。
3. **Living Timeline**：共学、相识和今天连接起来，最后为下一段故事保留空白。时间持续存在，内容持续生长。

## 14. 仍不够 Award-level 的地方

- **真实摄影缺位。** 目前能评审影像空间与裁切，尚不能评审同学、环境、瞬间与真实班级记忆的感染力。
- **内容声音还不够具体。** 软件工程共学与同学关系成立，但仍需班级真实的语气、事件与材料来证明独特性。
- **长页需要编辑判断。** 桌面的留白与 Timeline 较长；手机 Class Life 的图片节奏是否值得这段滚动，需要人工体验与取舍。
- **Timeline 只有三条样本。** 多年、重复月份、缺图和不同内容长度下的节奏尚未经过真实材料验证。
- **体验品质仍需人来判断。** 没有独立屏幕阅读器认证或设备帧率测量；构建和边界检查不能代替阅读体验评审。

## 16. 下一轮最值得看的五个问题

1. **开场身份**：“在一起／在发生”是否准确表达 ClassHub，是否需要更具体的班级信息来建立归属感？
2. **尺度与节奏**：大字、数字、留白和目录的反差是否恰当；哪里值得缩短，哪里需要停留？
3. **影像方向**：真实摄影应更偏观察式日常、共同活动还是集体肖像；哪些裁切值得保留？
4. **时间签名**：Pulse 与 Timeline 是否形成可记住的班级体验；年份关系是否自然，示例标签是否足够明确？
5. **手机与夜间**：390px 的重排是否仍保有个性和易读性；深红与灰绿夜间是否符合班级气质？

# 角色包美术素材制作笔记（生图 → 透明底 → 角色包）

> 桌宠角色包的美术流水线笔记。适合：用生图 API（豆包 Seedream）产出角色素材，
> 再处理成 `nlpack.zip` 里的透明 png。
> 2026-08 踩坑整理。角色包规范见 `docs/skin-pack-schema.md`。

## 一、生图 → 透明底（核心：色键方案）

### ❌ 方案 A：白底生图 + 「离白距离」抠图 —— 不推荐

- 白底生成后按「颜色离白多远」抠 alpha。
- **坑 1：白色/银白/高光被误抠成洞**。银色液态金属、冰面霜花、镜面反光都是接近白的
  ——离白距离方案把**材质的真实白色高光**当背景抠掉，身体开洞；拍出「半透明/缺口」。
- **坑 2：底部地板反光/影子清不干净**。白底生成的角色脚下常带地面反光带（甚至
  规则矩形浅色块），拆 alpha 后残留，观感像「角色站在半透明台子上」。
- **坑 3：形状漂移**。纯 prompt 生成的形状会和既有皮肤（如标准史莱姆）不一致
  ——长得太高/太瘦。**生图必须传参考图**（见下）。

### ✅ 方案 B：纯色幕布 + 色距关键抠图 —— 推荐

0. **幕布色按主体色选**（2026-08-29 补，用户提的）：色键第一原则是幕布色远离主体色。
   - 默认纯绿 `#00FF00`：适合暖色/金属/白色主体（月饼、岩浆、幽灵、金银）。
   - **绿色系主体（植物、玉、西瓜纹）→ 纯红幕 `#FF0000`**：红绿互补色距最远。
     别用品红——会干扰粉红花苞/红脸蛋。
   - 彩色杂色主体两头都沾 → 纯蓝幕 `#0000FF`。
     **实踩**：西瓜虫绿皮+红脸蛋，红幕把红脸蛋抠没了，蓝幕洞清零。
   - 白色系主体别用白幕，照用绿幕。
   - 绿幕抠绿主体不是不行（纯 #00FF00 与玉绿/森林绿色距 125+，仍在阈值外），
     但安全边距薄、半透明边缘易被拉向幕布色——能用红幕就别赌。
     **实踩**：莲花（绿叶+水珠高光）绿幕抠出 4.8 万像素的洞（开花帧最惨），
     换红幕后归零；龙龟/西瓜虫/含羞草侥幸在阈值内。
1. **生图时要求纯绿背景**（prompt 写死）：
   - 背景必须是 `flat solid pure green (#00FF00)`，无渐变、无阴影、无地面、
     无投影，角色悬浮（floating in empty space）。
   - 选绿色是因为不与常规材质（银/蓝/金/红/橙）冲突；品红/纯绿是抠图标准色。
2. **参考图保形状**：如果目标要复用已有形状（如普通史莱姆），把已有 skin 的
   `stand.png` 作为 `image` 参数传给生图 API，prompt 强调：
   "Recreate the EXACT SAME shape ... same silhouette ... ONLY change the material/color"。
3. **抠图（色距关键 chroma key）**：
   ```python
   # 1) 采样背景色：图像四角 30x30 中值（防全局白高光干扰）
   bg = 四角像素中值
   # 2) 色距 = 每像素与 bg 的欧氏距离
   dist = sqrt(sum((pixel - bg)^2, axis=2))
   # 3) alpha = clip((dist - 60) / 50, 0, 1)：dist<60 背景、>110 主体、中间渐变
   # 4) 最大连通域 + fill_holes（补内部：材质高光/反光不抠洞）
   # 5) spill 消除：**只压边缘过渡带**（按 edge=1-alpha/255 加权），
   #    全局压绿会把绿色主体（龙龟壳/西瓜纹/莲叶）洗灰——踩过
   # 6) 残余半透 <120 清 0 + 轻微羽化（GaussianBlur 0.8）
   # 7) 裁剪到内容 bbox，等比缩到统一高度（如 500px）
   # ※ 同角色多帧（stand/blink、开花序列）：必须按**全组 union bbox** 裁剪，
   #   各帧同尺寸同站位，否则切换瞬间跳变（脚本 /tmp/green_cut_group.py 模式）
   ```
4. **验证**（每次必做）：保存后检查
   - `img.mode == 'RGBA'` 且四角 `alpha == 0` —— 这一步能抓住「黑底/半透明矩形」残留。
   - alpha 直方图只有 0 和 255（或接近）——无半透明背景带。
   - 黑色像素（rgb<80 且 alpha>150）应只在身体内部（反光阴影），不在外围矩形。

### 关键坑（都踩过）

- **检查图覆盖成品图**：调试时若先 `bg.convert('RGB')` 存「衬黑底检查图」，又用
  同一个文件名存成品——**黑色矩形背景被写进了包里**。成品与检查图必须独立文件名，
  且保存后立刻读四角验证 `alpha == 0`、`mode == RGBA`。
- **纯白身体 vs 白背景**：白底方案不可解的冲突，绿底方案根治。
- **底部圆缘**：透明材质的底部圆缘（反光）是身体一部分，不要当成影子切——
  切了伤形状。只要生成时 prompt 无地面,验收时底部反光属材质特性。
- **眼睛定位干扰**：银色/金色高光会被误检为「眼睛」——画 blink 闭眼前，
  用「水平线成对 + 圆形度（|w-h|<18）+ 面积区间」过滤，宁可手动定坐标。

## 二、同 id 角色包覆盖导入（2026-08-29 起）

- `parsePack`：同 id 现在走 `warnings`（不再 errors 拒绝）；
- `preview`：已装版本 ≠ 导入版本时追加「版本差异：已装 vX，导入后将更新为 vY」。
- 用户确认后 `install` 覆盖（底层一直支持覆盖，之前是校验把它拦成了错误）。

## 三、声音素材备注

- 包内 `voice.*.mp3` 必须为包内路径（`voice/xxx.mp3`），解析时转 dataurl。
- 截图/剪辑注意：B 站视频音频可 yt-dlp 提取 m4a → ffmpeg 截段 → mp3，
  截取前先做能量分析定位语音段（转 wav 看 0.2s 窗 RMS）。

## 四、打包脚本要点

- 目录：`packs/<系列>/<角色>-pack/`（pack.json + skins/default/*.png + voice/*.mp3）
  与 `<角色>.nlpack.zip` 同目录；分发的 zip 内路径为 `pack.json` + `skins/...` + `voice/...`
  **不要带 `<角色>-pack/` 前缀**（parsePack 按根路径解引用，前缀会让素材找不到）。
